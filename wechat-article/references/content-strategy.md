## 选题流程（含知识库联动）

### ⚠️ 铁律（2026-05-18 新增）

1. **必须先读本文件 + published-history，再扫热点** — 不能先甩热点再回头对 SOP，会被打回
2. **HN 热门项目必须先确认内容再推荐** — 不能只看标题和分数（GenCAD 事件：HN #1 其实是 3D CAD 论文，跟 AI 编程无关）
3. **启动时先确认日期** — `date +%u`，不要靠猜
4. **每周至少 1 篇纯国内选题** — 不依赖海外信息源，从国内用户痛点出发（2026-05-26 新增）

### 信息源权重（2026-05-26 更新）

| 权重 | 来源 | 适用场景 |
|------|------|----------|
| 40% | **国内热点**（知乎、微博、B站、36氪、用户评论私信） | 国内用户直接相关的选题 |
| 30% | **海外热点**（HN、PH、Twitter） | 信息差选题、技术前沿 |
| 30% | **知识库 + 个人实践** | 深度内容、方法论 |

**国内信息源**（每天必扫）：
- `opencli zhihu hot --limit 10` — 知乎热榜（国内技术讨论）
- `opencli weibo hot --limit 10` — 微博热搜（大众关注）
- `opencli bilibili hot --limit 10` — B站热门（年轻用户）
- `opencli 36kr hot --limit 10` — 36氪（创业/商业）
- **公众号/视频号后台用户评论和私信** — 最真实的选题来源
- **微信生态变化** — 视频号新政策、公众号推荐算法变化、小程序更新
- **国内AI工具动态** — 通义、文心、Kimi、豆包等，大多数人用的不是 Claude

**海外信息源**（补充）：
- `opencli hackernews top --limit 10`
- `opencli producthunt today`
- `opencli twitter trending`

**为什么提高国内权重？**
- 你的读者在国内，他们关心的不是 HN 上什么火，而是「跟我有什么关系」
- 国内选题传播力更强（共鸣型内容转发率最高）
- 纯海外选题容易变成"翻译文"，损害"实战派"定位

### Step 1：确定当天母题
- 对照日更节奏表，确定当天的类型和母题
- 检查数据闭环里的母题健康度，如果某个母题超标则主动调整

### Step 2：搜索知识库（强制执行）
- 根据当天母题的关键词，搜索知识库：
  ```bash
  source ~/.openclaw/workspace-planner/kb-venv/bin/activate && python ~/.agents/skills/kb-search/scripts/kb_search.py "[母题关键词]" 3
  ```
  - 也可以搜结构化素材：`... -c content_materials`
- 将命中的素材记录下来，作为选题卡片的「素材来源」
- **如果搜索到高质量素材**：优先基于该素材构建选题
- **⚠️ 素材归属检查（2026-07-25 新增）**：知识库素材如果是别人的活动/演讲/案例（如破局大会分享、某大V的方法论），选题不能把别人的案例当主体——那等于免费给对方打广告。**规则：素材是你的论点的论据，不是文章的主角。** 自检：「这个选题是讲我的认知，还是讲别人的成功故事？」如果删掉那个人名/活动名文章就不成立，说明选题依附性太强，换角度或换选题
- **如果搜索结果不相关**：使用选题库中的现有卡片

### Step 3：检查选题库
- 读 `published-history.md`，避免最近发过相同角度
- 从选题卡片中挑选匹配当天母题的选题
- 如果知识库有命中素材，更新对应选题卡片的「素材」字段

### Step 4：国内覆盖度验证（强制执行，2026-05-12 新增）
- 对每个候选选题，**必须**用 `opencli google search "[选题关键词] 中文"` 验证国内是否已覆盖
- 判断标准：
  - 国内零覆盖 = 最佳信息差 ✅
  - 国内1-2篇覆盖但不够深，你有独特视角（个人实测/不同角度）= 可做 ✅
  - 国内主流媒体全覆盖且你没有新角度 = 放弃 ❌
  - 国内全覆盖但你有人物/事件的新信息 = 可做 ✅
- **这条规则是因为 2026-05-12 差点发了三个月前的旧闻**，HN 2300+ 分但国内 36氪/虎嗅/新浪早报过了

### Step 5：互动预判筛选（强制执行，2026-06-15 新增）

选题确定前，必须通过互动三问：

1. **转发驱动**：读者看完会不会想@某个人或转发到朋友圈？（实用干货/认知升级/情绪共鸣，至少占一条）
2. **评论驱动**：读者看完会不会想说点什么？（争议观点/提问钩子/共鸣吐槽）
3. **收藏驱动**：读者看完会不会觉得"我得存下来"？（清单/方法/资源/对比表）

**三条都不占 = 换选题，不犹豫。**

> 数据支撑："AI修bug删了2.8万行代码"1479阅读但0评论——因为读者看完觉得"哦，知道了"，没有表达欲。阅读量不等于互动量。

### Step 6：输出选题推荐
- 给出 3-5 个推荐选题，每个带 50 字简介
- 标注素材来源（知识库命中 / 选题库卡片 / 新生成）
- **标注每个选题的互动预判**（转发/评论/收藏各打 ✅ 或 ❌）

> **为什么要搜索知识库？** 知识库里存的是你在素材群入库的新鲜素材、行业热点、读者反馈。
> 这些素材比选题库里的静态卡片更有时效性和真实感。
> 不搜索知识库 = 浪费了你手动入库的素材。

## 选题库（卡片式）

> 标记规则：⬜ 待发 / ✅ 已发 / 🔥 表现好 / ❌ 表现差
> 每张卡片包含：核心论点、共鸣点、素材、角度、OpenClaw 结合点

### 母题 1：手艺人困境

**卡片 1**：写了 10 年代码，我才明白：技术越好，越容易穷忙 ⬜
- **核心论点**：技术深度不等于商业价值，程序员最大的误区是把技术积累等同于能力积累
- **共鸣点**：学了那么多框架，收入没变过
- **素材**："大几百小时学框架收入+0"（今天文章用过的真实数据）、CI/CD 精致浪费时间的比喻
- **角度**：不是否定技术，是重新定义"积累"——积累应该用"赚钱能力"衡量
- **OpenClaw 结合**：用 OpenClaw 把技术能力转化为交付能力，省下的时间做商业化

**卡片 2**：程序员的最大陷阱：你以为在积累，其实在消耗 ⬜
- **核心论点**：大部分"学习"其实是在缓解焦虑，不是在提升自己
- **共鸣点**：看到新技术就焦虑，不学怕落后
- **素材**："给没油的车装尾翼"比喻、React/Next.js/Vue/Tailwind 轮转
- **角度**：和"数字力工"呼应——如果只是重复劳动，再熟练也只是更快的数字力工
- **OpenClaw 结合**：OpenClaw 让 AI 帮你写代码，你专注在设计层面

**卡片 3**：手艺人的终局：要么被替代，要么变成生意人 ⬜
- **核心论点**：AI 正在吃掉"手艺人"的生存空间，出路只有一条——从执行者变成设计者
- **共鸣点**：Claude/Codex 能写代码了，我还能干嘛？
- **素材**：Codex CLI 全平台化、Cursor 600亿估值、今天群里"程序员职业路径被打破"的讨论
- **角度**：不是悲观论调，是给一个明确的方向——生意人 = 获客 + 交付 + 收款
- **OpenClaw 结合**：OpenClaw 就是从手艺人到生意人的工具

**卡片 4**：AI 编程不是让你写得更快，是让你从手艺人变成设计者 ⬜
- **核心论点**：AI 编程的真正价值不是提效，是让一个人能同时做设计和执行
- **共鸣点**：用 AI 写代码后发现自己不知道该干嘛了
- **素材**：Karpathy "全是 AI 的思考"、个人从手动到自动化的经历
- **角度**："提效"是老板视角的第4层优先级，"变成设计者"才是第1层
- **OpenClaw 结合**：OpenClaw 的 Skill 体系就是"设计者"的工作方式

### 母题 2：时代红利变了

**卡片 5**：10年全栈 vs 3年全栈 + 2年 SEO：AI 时代的技术投资回报率 ⬜
- **核心论点**：技术 + 获客能力的组合 > 纯技术深度
- **共鸣点**：10年经验和3年经验的人抢同一个岗位
- **素材**：今天群里"程序员职业路径被打破"的讨论、老板视角优先级排序
- **角度**：不是 SEO 比 10 年全栈重要，而是"商业化能力"是新的核心竞争力
- **OpenClaw 结合**：OpenClaw 自动化内容生产 = 获客能力的杠杆

**卡片 6**：OpenAI Codex 全平台化：AI 编程工具的终局形态？ ⬜
- **核心论点**：AI 编程工具正在从"终端 agent"进化为全平台生态，竞争格局在变
- **共鸣点**：Codex 免费用 ChatGPT 账号登录、支持 IDE/桌面/终端/Web
- **素材**：今天安装体验 Codex v0.129.0 的真实体感、和 Claude Code 的对比
- **角度**：不是工具测评，是从工具竞争看 AI 编程行业的走向——终局是"生态"不是"单点工具"
- **OpenClaw 结合**：OpenClaw 的多 Agent + Skill 体系 vs Codex 的全平台化，两种不同的终局路线

**卡片 7**：别拿旧地图走新战场：AI 时代的 3 个误区 ⬜
- **核心论点**：大部分人对 AI 的理解还停留在"替代程序员"，真正的机会在别处
- **共鸣点**：前端转全栈、后端学 AI——这些都是在用旧地图
- **素材**：今天讨论的"小B企业的 Agent 工作流需求"、跨境电商/留学中介/机加工企业的案例
- **角度**：真正的机会不在"卷技术"，在于"找需求"——小B市场有大量未满足的自动化需求
- **OpenClaw 结合**：OpenClaw 的 Skill 串联 + Agent 工作流就是服务小B的工具

**卡片 8**：2026 年还有红利吗？有，在 AI + 出海 ⬜
- **核心论点**：旧红利（房产、互联网、移动互联网）已结束，新红利在 AI + 出海
- **共鸣点**：父母错过房产红利，这次不想再错过
- **素材**："房产红利"文章（30阅读但6.7%转发率）、短视频比公众号高一个量级的数据
- **角度**：不是喊口号，是用具体数据说明出海市场为什么还没卷完
- **OpenClaw 结合**：OpenClaw 降低了一人企业出海的技术门槛

### 母题 3：专业 ≠ 成交

**卡片 9**：信任才是今天最高级的商业基础设施 ⬜
- **核心论点**：在信息过载的时代，信任 > 技术 > 价格
- **共鸣点**：技术比你好的人很多，但客户选的是他信任的那个人
- **素材**：公众号 27 篇文章带来的信任积累、有读者主动找你聊合作
- **角度**：公众号不是"写文章"，是"让客户在见你之前就信任你"的自动化信任建设系统
- **OpenClaw 结合**：OpenClaw 自动化内容生产 = 自动化信任建设

**卡片 10**：一人企业的真相：获客系统比产品更重要 ⬜
- **核心论点**：大部分一人企业的失败不是因为产品不好，是因为没人知道
- **共鸣点**：做了产品没人用、发了朋友圈没人看
- **素材**："5个产品只有1个赚到钱"的假设案例、公众号从个位阅读到119的过程
- **角度**：产品是 1，获客是后面的 0——没有 1 后面的 0 没意义，但只有 1 也只是 1
- **OpenClaw 结合**：公众号 + SEO + 社媒 = OpenClaw 能自动化的获客系统

### 母题 4：普通人阶级跃迁

**卡片 11**：普通人跃迁的公式：新技术 + 新市场 + 持续输出 ⬜
- **核心论点**：三个条件缺一不可：新技术（AI）+ 新市场（出海）+ 持续输出（公众号/社媒）
- **共鸣点**：知道 AI 是机会，但不知道从哪下手
- **素材**：个人从打工人到一人企业的路径、27篇文章的持续输出记录
- **角度**：大部分人只做了第1个（学AI），忽略了第2和第3
- **OpenClaw 结合**：OpenClaw 让"持续输出"的成本降到最低

### 母题 5：一人企业结构

**卡片 12**：一人企业的技能优先级：赚钱 > 降本 > 合规 > 提效 🔥 （今日待发）
- **核心论点**：一人企业 = 一个人当老板，必须用老板视角选技能
- **共鸣点**：程序员最爱卷提效，但老板根本不关心提效
- **素材**：26篇文章数据、短视频403播放数据、OpenClaw 自动化压缩一周到一天
- **角度**：程序员切入 + 通用收尾，"缓解焦虑"金句有传播力
- **OpenClaw 结合**：公众号=赚钱技能，OpenClaw=降本技能

**卡片 13**：一人企业的最小结构：3 个系统，缺一不可 ⬜
- **核心论点**：获客 + 交付 + 收款，三个系统构成一人企业的最小闭环
- **共鸣点**：副业做了很久但始终没收入，可能缺的不是产品而是系统
- **素材**：OpenClaw 搭建的内容获客系统（选题→初稿→排版→发布全自动化）
- **角度**：不是告诉你"要做三件事"，而是帮你检查"你现在缺哪一个"
- **OpenClaw 结合**：OpenClaw 本身就是这三个系统的自动化引擎
