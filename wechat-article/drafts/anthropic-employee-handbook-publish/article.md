# 连 Anthropic 都在给 AI 做"岗前培训"：失控率从 54% 降到 7%

前两天刷到一条消息：**Anthropic 给 Claude 写了份"员工手册"，失控率从 54% 直接砸到 7%。**

没换模型，没加算力，就是多写了几行指令。

我自己跑了 3 个月 AI Agent，最大的感触就一句话：**AI 不好用，90% 是你没教好，不是它不行。**

---

## 发生了什么

Anthropic 的团队发现一个问题：Claude 在执行复杂任务时，经常"跑偏"。

比如你让它帮你整理客户反馈，它可能会自作主张帮你写一份营销方案。你让它做数据分析，它可能会顺便帮你预测下个季度的趋势。

听起来很贴心对吧？但在企业场景里，这就叫**失控**。

AI 做了你没让它做的事，而且你还不知道它做了。

Anthropic 的解决方案出人意料地简单：他们给 Claude 写了一份超级详细的系统指令，把它当成一个**新入职的员工**来培训。

这份"员工手册"里写了什么？大概就是：你的角色是什么，你能做什么，不能做什么，遇到模糊的情况怎么处理，什么必须请示。

结果：失控率从 54% 降到 7%。

**同一模型。同一能力。只是上下文更清晰了。**

## 这件事的本质

我看完这个实验，第一反应不是"Anthropic 真厉害"，而是：**这不就是我每天都在做的事吗？**

我用 OpenClaw 跑了 3 个 AI Agent，一个写公众号，一个写知乎，一个负责调度。每个 Agent 都有自己的"员工手册"——SOUL.md 写性格，AGENTS.md 写职责，TOOLS.md 写工具用法，MEMORY.md 写历史经验。

最早的时候，我也犯过同样的错：一个 AI 干所有事，公众号的"爆文公式"混进了知乎回答，知乎的"金句"跑进了产品文档。

**一个 AI 干所有事，上下文越来越乱。**

后来我把它们拆成 3 个工作区，每个都有独立的"岗位说明书"。效果立竿见影：内容质量提升，上下文不再串台，而且每个 Agent 都能积累自己领域的经验。

Anthropic 用 54% → 7% 的数据证明了一件事：**AI 的表现，80% 取决于你怎么定义它的"工作环境"，20% 才是模型本身的能力。**

Marc Andreessen 最近在 a16z 播客里说了句大实话："你的 Agent 已经独立于它所运行的模型了。"真正决定 AI 表现的，不是跑在下面的那个大模型，而是你给它搭建的整个系统。

## 一人企业怎么做

你可能会说："Anthropic 是大公司，有专门的团队做系统设计，我一个人怎么搞？"

恰恰相反，一人企业更需要这套东西。因为你没有团队帮你兜底，AI 犯错的代价全压在你一个人身上。

我花了一周时间，给我的 3 个 Agent 各写了一套"岗位说明书"。

拿公众号这个 Agent 举例。我给它写了 4 个文件：**SOUL.md** 定义性格——冷静、数据导向、不说废话；**AGENTS.md** 写清楚它负责选题、大纲、初稿、配图，但不碰数据分析和用户管理；**TOOLS.md** 列出它能用的工具和优先级；**MEMORY.md** 记录历史经验——什么标题点击率高，什么时间段发效果好，什么话题容易翻车。

最早没这么干的时候，我吃过大亏。

有一次我用一个 AI 会话同时写公众号和知乎。结果公众号的"爆文公式"混进了知乎回答——满屏加粗、感叹号、"你还在 XX 吗"。知乎用户看到这种风格直接划走。知乎的"金句体"又跑进了产品文档，读起来像散文而不是说明书。

**一个 AI 干所有事，上下文串台，内容全废。**

拆完之后效果立竿见影。每个 Agent 只专注自己的领域，风格不再串，经验还能积累。现在这 3 个 Agent 每天自动跑，我只需要做最后的确认和微调。

Anthropic 能把失控率从 54% 降到 7%，核心就一件事：**把过去的失败经验写进系统指令。** AI 不需要每次从零试错，它站在了历史经验的肩膀上。

我每个 Agent 的 MEMORY.md 就是干这个的。哪怕只是粗糙的记录——"深夜发布点击率低 40%"、"标题带数字的阅读量高 2 倍"——这些碎片经验写进去之后，AI 的输出质量肉眼可见地提升。

**不是 AI 不行，是你没把经验传给它。**

## 反常识结论

大多数人用 AI 的方式是：买最贵的模型，发最短的指令，然后抱怨结果不好。

**这就像招了个哈佛毕业生，啥也不交代就让他干活，然后骂他蠢。**

我花了一周设计这套系统。一周之后，3 个 Agent 开始自动运转。相比之前每天花 3-4 个小时手动调教 AI，这笔投入早就回本了。

一人企业的壁垒，从来不是你能买到多强的模型。**是你能设计多好的系统，让 AI 稳定地为你运转。**

Anthropic 用 54% → 7% 帮你算了一笔账：系统设计的 ROI，远超模型升级。
