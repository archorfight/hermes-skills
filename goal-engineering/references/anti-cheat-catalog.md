# 防作弊条款库

> 按场景分类的常见偷懒方式和堵死条件。写 goal 时从对应场景里挑选适用条款。

---

## 代码开发类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 删测试降低标准 | 测试数量不得减少，覆盖率不得下降 |
| 只改简单函数凑数 | 明确列出必须修改的核心文件/函数 |
| 注释掉失败的测试 | git diff 不允许出现注释测试代码的改动 |
| 用 mock 绕过真实逻辑 | 验收命令必须包含集成测试，不能全 mock |
| 复制粘贴重复代码 | 验收时跑 lint 检查重复率 |

## 部署上线类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 只改代码不部署 | 必须回传可访问的 URL |
| 部署旧版本凑数 | commit_sha 必须是最新 commit |
| 部署后不验证 | curl 返回 200 + 页面截图 |
| 环境变量没配 | 验收时测试核心功能链路（如表单提交） |
| 域名没绑定 | URL 必须是正式域名，不能是 preview 链接 |

## 内容生产类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 字数不够 | 字数必须在指定范围内（如 2000-3000 字） |
| 编造引用和数据 | 每个数据点附来源 URL |
| 抄袭已有文章 | 原创度检查，不得与已发布文章重复率 >30% |
| 配图不相关 | 配图必须附alt文本和来源标注 |
| 跳过审校步骤 | 必须回传审校 checklist 的填写结果 |

## 调研分析类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 编造搜索量/数据 | 每个数据附工具名称 + 查询日期 + 截图 |
| 只给热门词不评估竞争 | 每个关键词必须附 SERP 前 10 名分析 |
| 用过时数据 | 数据查询日期必须在 7 天内 |
| 只列竞品不给分析 | 每个竞品必须附：定价、功能对比、差异化机会 |
| 结论模糊不可执行 | 每条结论必须包含具体的行动建议 |
| AI 生成式空话 | 每条结论必须附原始数据或 URL，不接受"一般来说" |

## 截图采集类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 截图无窗口边框 | macOS 窗口边框必须可见 |
| 截图内容不相关 | 每张截图附文件名说明 + 来源 URL |
| 分辨率太低 | 截图宽度 >= 1280px（桌面）或 375px（移动端） |
| 截了空白页或加载中 | 截图前必须等待页面完全加载 |

## 通用条款

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 声称完成但没贴证据 | 证据回传是硬性条件，没证据 = 未完成 |
| 超出预算时间 | 超时交"目前进度 + 还没完成什么"，不算失败 |
| 改了不该改的文件 | git diff --stat 检查，不在白名单内的改动 = 失败 |
| 跳步执行 | 明确列出必须按顺序完成的步骤 |
| 返回结果太模糊 | 返回结果必须包含：做了什么、证据、未完成项 |
