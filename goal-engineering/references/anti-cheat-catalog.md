# 防作弊条款库

> 按场景分类。写进 goal 的「防偷懒」段。

---

## 代码类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| skip 测试 / `|| true` / `|| exit 0` | goal 里写明：测试必须全通过，贴最终输出（不能只贴"PASS"） |
| mock 被测对象 | 要求贴真实 API 响应片段或真实文件内容 |
| 删测试降低阈值 | 基线不可退：写明当前测试数/覆盖率，结果必须 ≥ 基线 |
| 改配置文件假装通过 | 边界白名单：只允许改指定路径 |
| 提交无关文件凑 commit | `git diff --stat` 必须只包含白名单内文件 |

## 部署类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 声称已部署但没贴 URL | 必须回传可访问的 URL + `curl -sI` 200 证明 |
| 只部署桌面端没做移动端 | 必须贴移动端 viewport (375px) 截图 |
| 部署了旧版本 | 要求贴 commit_sha + 部署 URL，主 agent 用 sha 验版本 |
| 跳过 SEO 检查 | 必须回传 meta tags + sitemap.xml + robots.txt 状态 |

## 内容产物类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 声称写完但没贴文件路径 | 必须回传 article.md 路径 + 字数（在目标范围内） |
| 配图不合规 | macOS 窗口边框 + 内容占比 >70% + 来源标注 |
| 用 placeholder 混充 | 产物里不能有 TODO/FIXME/placeholder 文本 |
| 字数不够或超长 | 明确字数范围，超出范围 = 返修 |

## 调研类

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 编造数据/引用 | 每条结论必须附可复现的 URL 或命令 |
| 用过时数据 | 来源日期必须标注，主 agent 暗卷随机抽一条验证日期 |
| 只查一个来源 | 预算里写明最少 N 个来源 |
| 凑数结论 | "宁收 2 条实的，不收 10 条凑的"写进 goal |
| 跳过否定证据 | 有利和不利证据都要列，不能只列支持结论的 |

## 通用

| 偷懒方式 | 堵死条件 |
|----------|----------|
| 声称完成但没回传证据 | goal 模板里 Evidence 段是必填的 |
| 悄悄改了不该改的文件 | 暗卷跑 `git diff --stat` 对比白名单 |
| 重跑时偷偷改基线 | 基线数字写进 goal，不可退 |
