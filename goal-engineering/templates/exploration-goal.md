# 探索型 Goal 模板

> 适用于：调研、选型、分析、关键词研究、竞品分析
> 核心原则：每条结论必须可复现（附 URL 或命令），编造引用 = 不合格，此路不通 = 合格（带证据）

---

## 模板

```
## 目标
[要回答什么问题]

## 完成条件
- 结论 ≤ N 条，每条附来源 URL + 日期
- 宁收 2 条实的，不收 10 条凑的

## 证据
- 每条结论必须可复现（给 URL 或命令）
- 编造引用 = 不合格
- 数据类结论附原始数据来源

## 预算
- 最多查 N 个来源 / N 分钟
- 烧完交"目前最优 + 还没排除什么"

## 此路不通 = 合格
- 带证据证明某方向是死路（死因 + 原始输出）
- 不需要所有方向都有结论
```

---

## 示例：关键词调研

```
## 目标
找出 og-image generator 这个工具站的 5 个高价值目标关键词。

## 完成条件
- 结论 ≤ 5 条，每条附：月搜索量、竞争度、SERP 前 10 名 URL
- 来源：Google Keyword Planner / Ahrefs / SERP 实测
- 宁收 2 条实的，不收 10 条凑的

## 证据
- 每个关键词附 SERP 截图或搜索结果 URL
- 搜索量附工具名称和查询日期
- 编造数据 = 不合格

## 预算
- 最多查 15 个来源 / 20 分钟
- 烧完交"目前最优 3 个 + 还没排除的 5 个"

## 此路不通 = 合格
- 某关键词搜索量太低 → 带搜索结果截图证明
- 某关键词 SERP 全是权威站 → 带前 10 名域名列表
```

## 示例：竞品分析

```
## 目标
分析 3 个 OG image generator 竞品的定价策略，给出我们的定价建议。

## 完成条件
- 结论 ≤ 3 条竞品 + 1 条定价建议
- 每条附：竞品 URL、定价页面截图、免费额度、付费起步价
- 定价建议附成本核算（服务器成本 + API 调用成本）

## 证据
- 竞品定价页 URL + 访问日期
- 如竞品无公开定价 → 截图联系销售页面 + 标注"需询价"
- 编造定价 = 不合格

## 预算
- 最多查 10 个来源 / 15 分钟

## 此路不通 = 合格
- 竞品已下线 → 带页面截图 + Wayback Machine 链接
- 竞品无独立定价（捆绑销售）→ 带母产品定价页
```

## 示例：选品方向调研

```
## 目标
从 intel-pipeline 最近一周的素材中，找出 3 个值得一做的工具站方向。

## 完成条件
- 结论 ≤ 3 条，每条附：痛点来源帖 URL、搜索量估算、竞品数量
- 每条标注：需求强度（高/中/低）、变现路径、技术难度
- 宁收 1 条实的，不收 3 条凑的

## 证据
- 痛点帖附原文 URL + 引用原文关键句
- 搜索量附 Google Trends 或 Keyword Tool 截图
- 竞品数量附 Google 搜索结果数

## 预算
- 最多查 20 个来源 / 30 分钟

## 此路不通 = 合格
- 某方向搜索量低但痛点真实 → 标注"小众但精准"，附证据
- 某方向已被大厂占据 → 带竞品列表 + "不建议正面竞争"
```
